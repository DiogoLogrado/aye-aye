# About the name and logo

The aye-aye is a lemur from Madagascar that finds food in an unusual way. It taps on tree bark with a long, thin finger, listens for hollow spots, and pulls out what's hidden inside. Searching a database works much the same way.

The logo shows an aye-aye peeking over a database stack, its paws gripping the lid's edge and its bushy tail curling up on the right. It's drawn in two colors, white on green, so it stays readable at small sizes.

The source is [`assets/icon.svg`](../assets/icon.svg). `npm run icons` generates the Windows icon and the favicon from it.
